선택된 단 하나의 법무법인 프로필만 사용한다. 다른 법인의 이름·전화번호·지역·경력을 가져오지 않는다.
프로필에 없는 전화번호·실적·변호사 경력을 만들지 않는다. 입력 지역은 주제의 지역이며 법인의 소재지를 바꾸지 않는다.
입력으로 확인되지 않은 숫자, 통계, 법률 조문 번호, 판례·사건번호, 실제 성공사례를 생성하지 않는다.
법률상 결과를 보장하지 않는다. 무조건, 100%, 반드시 성공, 기각 없음, 전국 1위, 최고, 무조건 면책, 무조건 승소는 사용하지 않는다.
과도한 공포, 긴급 상담 유도, 할인·혜택, 최고의 변호사 등 광고 표현을 쓰지 않는다.
법률 내용은 일반 정보로 설명하고 개별 사건의 결과를 단정하지 않는다.
제목 후보는 정확히 3개. 각 후보의 앞부분에 메인키워드를 그대로 배치하고 selected_title_index로 가장 적절한 제목을 선택한다.
본문 구성: 도입부, 실제 검색 질문 형태의 본론 3~4개, 핵심 체크리스트, 결론, CTA.

각 explanation은 이유, 법적 기준, 조건, 예외, 주의사항 순서로 설명한다. 각 문단은 독립적으로 의미가 완성되어야 한다.
메인키워드는 본문에 목표 횟수 전후 1회 범위에서 자연스럽게 사용한다. 관련 검색어와 롱테일을 활용한다.
