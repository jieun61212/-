법률 원고 스튜디오 — Windows 사용방법

1. 받은 ZIP 파일을 마우스 오른쪽 버튼으로 클릭해 '압축 풀기'를 선택하세요.
   ZIP 안에서 직접 실행하지 말고, 압축을 푼 폴더를 여세요.

2. '처음 설치.cmd'를 더블클릭하세요. 이 작업은 처음 한 번만 필요합니다.
   Python이 없으면 Python 공식 다운로드 페이지가 열립니다.
   페이지 하단 Files에서 'Windows installer (64-bit)'를 다운로드하세요.
   설치 화면의 'Add python.exe to PATH'를 체크하고 'Install Now'를 누르세요.
   설치가 끝나면 '처음 설치.cmd'를 다시 더블클릭하세요.
   설치 완료라는 문구가 나오면 창을 닫으세요.
   필요한 라이브러리는 ZIP에 포함되어 있어 따로 명령어를 입력할 필요가 없습니다.
   Windows 10/11 64비트와 Python 3.12 64비트 기준입니다.

3. '프로그램 시작.cmd'를 더블클릭하세요.
   브라우저에 프로그램이 자동으로 열립니다. 검은 실행 창은 열어 두세요.
   처음에는 API 키가 없어도 '예시 모드'로 기능을 확인할 수 있습니다.

4. 프로젝트와 법무법인을 선택하세요. AI 모드에서는 판결문 PDF를 넣고 원고 생성만 누르면 키워드·서브키워드·주제가 자동 선정됩니다.
   판결문을 직접 익명화할 필요 없이 분석·원고에서 개인정보를 자동 처리합니다.
   실제 검색량은 측정하지 않으며 검색 의도에 맞는 후보를 추천합니다.
   PDF가 없는 일반 글이나 예시 모드에서는 메인키워드와 주제를 입력하세요.
   '원고 생성'을 누르면 오른쪽에 예시 원고가 나타납니다.
   복사, txt 저장, docx 저장, 작성 이력을 확인하세요.
   예시는 기능 확인용입니다. 실제 AI 작성이나 판결문 사례 생성은 API 연결 후 가능합니다.

5. 다음부터는 '프로그램 시작.cmd'만 실행하면 됩니다.
   종료하려면 검은 실행 창에서 Ctrl+C를 누르고 창을 닫으세요.

작성 이력은 같은 폴더의 data에 저장됩니다. 이력을 유지하려면 data를 삭제하지 마세요.
API 키 설정은 나중에 진행해도 됩니다. 키를 채팅이나 코드 파일에 넣지 마세요.

이번 배포물은 Python 기반 프로그램이며 설치가 필요 없는 단일 exe는 아닙니다.
현재 개발 환경에서 앱과 자동 브라우저 열기 로직을 검증했으나,
실제 Windows PC에서의 설치와 실행은 아직 확인하지 못했습니다.
문제가 생기면 오류가 나온 창을 캡처해서 보내주세요. 비밀정보는 가려 주세요.
